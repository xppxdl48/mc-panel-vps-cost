# 游戏服务器面板：面板服和 VPS 怎么选，开一个 MC 服每月要花多少钱

搜"游戏服务器面板"的人其实分成两拨，需求差得挺远。

一拨是想找一套能装在自己机器上的控制面板软件，比如 MCSM、Pterodactyl 这类；另一拨只是想要一台"打开网页就能开服"的服务器，不想碰 SSH，不想装环境。前者研究的是软件架构，后者研究的是月租多少钱、能带多少人。

这篇文章两条线都讲，顺手把雨云（RainYun）家的两种面板服拆开对比，因为它的产品线正好覆盖了这个关键词背后的两类意图。

## 先分清楚：面板软件和面板服不是一回事

**面板软件**是管理工具。你得先有一台机器，再把面板装上去，然后用它来开服、传文件、看日志。常见的有：

- MCSManager（MCSM）：开源、分布式、多实例，支持 Docker，中文界面，在国内 MC 圈里用得很多
- Pterodactyl：PHP + React 架构，分 Panel 和 Wings 两部分，每个游戏服跑在独立 Docker 容器里，社区维护的 "egg" 模板支持 100 多款游戏
- Crafty Controller：Python 写的单容器方案，只服务 Minecraft Java / 基岩版和 Hytale，没有外部数据库依赖
- AMP：CubeCoders 出的商业面板，支持 Windows / Linux / macOS，覆盖面广
- Multicraft：老牌商业面板，稳定但授权费用不低，主要面向 Minecraft 和做托管生意的团队

**面板服**是托管产品。面板已经装好、配好、挂在网页上等你登录，你只需要选配置、付款、开服。雨云的游戏云就把这条路单独拆成了产品线，分雨云面板和 MCSM 面板两种。

搞清楚这个区别很重要，因为它们的成本结构完全不同。

## 自己装面板，要先付出一台机器的代价

以 Pterodactyl 为例，单节点最少要跑四个容器：Panel、MariaDB、Redis、Wings。管理层的内存占用大概在 500MB 到 1GB，磁盘约 2GB，首次部署按文档走一遍通常要 30 到 60 分钟，还需要一个带 HTTPS 的域名。

Crafty Controller 轻得多，单容器、内置 SQLite，官方说五分钟就能起第一个服务器，管理开销 256–512MB。代价是它只管 Minecraft 系，SteamCMD 类游戏的支持还在开发中，也不支持多节点。

MCSM 属于中间路线：开源、分布式、支持多实例和 Docker，可以集中管理多台物理机器，也有多用户权限系统，适合想长期自己维护面板的人。

算一笔账：如果你因此需要单独买一台 1核2G 的机器来跑面板，那台机器的钱本来就是白花的。面板服省掉的正是这部分。

## 雨云的两种面板服，差在哪

雨云成立于 2018 年，游戏云是它的核心产品之一。面板服这块它做了两个方向：

**雨云面板**是自研的，跑在 Kubernetes 集群上，主打高可用。特色是支持 CPU 升降级、可以直接切换 CPU 机型（目前有 i9 14900KS 和 Platinum 8259CL 两档可选），还带备份和 MySQL 功能。适合单端场景、想省事的新手服主。

## 计费方式选错了，一个月能多花不少钱

雨云支持两种计费模式，面板服还额外提供按天计费。

**固定计费**就是按月租收，不管你用多少。适合长期开着、半夜还有人在线的服务器。

**动态计费**是基础租金加上"CPU 电量"的额外日结费用，只在 CPU 实际消耗超出发放的基础电量时才多扣。它解决的是峰值性能需求——你想省钱就用低配日租，需要火力的时候性能不会掉，但账单会涨。

**按天计费**是面板服专供，每天定时用余额结算下一天日租。

选哪个有个简单的判断法：如果服务器一个月里有十天以上是关着的，按天付费通常更划算；如果基本天天有人上线，固定计费更省心，也不用担心某天 CPU 跑满被多扣钱。

## 几个下单前值得先知道的限制

- **面板服是 NAT 模式**，没有独立公网 IP，和别的用户共用一个出口，靠端口映射对外。默认开放 15 个端口，开一个 MC 服够用，想同时开多个服务端就要数着来了。
- **NAT 模式共享 150G 高防**，BGP 线路。这是它的网络优势，但也意味着你不能单独买独立 IP 加在面板服上——那需要走 VPS。
- **面板服的 CPU 机型在雨云面板上可以切换**，但游戏云 VPS 的 CPU 买了就不能换。这是很多人下单时没注意到、之后才后悔的一点。
- **上传的压缩包必须是 ZIP 格式**，面板在线解压只认这一种。
- 一个真实的小坑：同时开多个 MCSM 面板时，切换登录前要清一下浏览器缓存，否则会串号。

## 谁适合买面板服，谁该绕开

**适合买的**：和朋友联机的小型服务器、只跑一个 MC 端、不想碰命令行、想按天关服省钱、需要快速开服验证玩法的人。开泰拉瑞亚、饥荒这类官方已支持一键开服的场景，面板服几乎没有理由不选。

**该选 VPS 或者自建面板的**：要在一台机器上同时跑游戏服和其他服务；要独立公网 IP；要改内核参数或装自定义环境；要开大型群组服（BungeeCord / Velocity 一整套）；或者你自己就是做托管生意、需要多节点管理。

## 常见问题

**面板服能不能装 Pterodactyl 或者 MCSM？**
面板服没有系统级权限，装不了。雨云面板和 MCSM 面板是它给你准备好的。想自己装面板，要买游戏云 VPS 或云服务器。

**开一个十人左右的 MC 生存服，最低配够吗？**
1.16 及以下版本的纯净插件服，2核4G 的 Platinum 8259CL 档位基本能撑住。1.18 以上版本对单核性能的要求大约是 1.16 的两倍，1.12.2 的三倍，建议直接选 Ryzen 5900X 或更高，内存上到 4G 以上。

**动态计费会不会突然扣很多？**
只有 CPU 消耗超出每日赠送的基础电量才会额外计费，而且是日结，账户留够余额就能看到每天的消耗。真正的风险是服务器长期满负荷跑却不换固定计费。

**免费的面板服靠谱吗？**
能用，但 CPU 偏弱（多为 E5 2666V3、Platinum 8275cl 这类多核强、单核弱的机型），适合低版本小服或者挂机服。高版本模组服别指望。

**退款麻烦吗？**
官方支持 7 天无理由退订，每个账号限 3 次，自助就能操作，不用走客服流程。
